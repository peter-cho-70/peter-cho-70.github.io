# peter-cho-70.github.io

개인 프로젝트 문서 허브. 각 프로젝트의 `<project>-docs` 저장소(공개, GitHub Pages)로 연결되는 랜딩 페이지.

- [MARS / Master 문서](https://peter-cho-70.github.io/mars-master-docs/)
- [NewsControl 문서](https://peter-cho-70.github.io/newscontrol-docs/)
- [StockMind 문서](https://peter-cho-70.github.io/stockdashboard-docs/)

새 프로젝트 문서 사이트를 추가하려면 `index.html`의 `.grid` 안에 카드를 하나 추가한다.

> 허브 맨 위 "외국어 학습" 카드는 `myremember-vault/language-study.html`(비밀번호 게이트)로 연결된다. 나머지 문서 사이트는 비밀번호 없이 공개. 이 카드는 `data-check`가 없어 자동 정렬 대상이 아니라 항상 맨 위에 남는다.
